# A LA DERIVA 3D

Survival en 3D a la deriva: gestiona agua y comida, pesca, afronta tormentas y eventos diarios
(tiburones, buques fantasma, motines) y busca tierra firme antes de que el mar te gane.

Juega en [games.iaen.es](https://games.iaen.es).
